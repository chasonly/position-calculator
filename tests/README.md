# HTML 行情验证

本轮仅修改主 HTML 和验证文件，未修改 Android 工程、构建资源或 APK。

## 当前实现

- 选中期货合约后，与报价并行读取东方财富 `redis?msgid={市场}_{品种序号}_info` 合约资料，校验品种代码后由 `jydw` 和 `bjdw` 换算乘数，由 `zcjybzj` 解析资料基准保证金比例。国债百元净价使用面值除以 100 的乘数。无法识别或读取失败的参数留空，避免沿用上一品种参数；报价仍可正常填入。
- 保证金参考值是合约资料的基准比例，不是当日调整后的交易所或客户实际保证金；页面明确标注口径，折叠来源说明提供链接、读取时间（不冒充资料更新日期）和单位。用户应使用账户实际比例修正。
- 手动保证金率按“交易所:品种”保存在 localStorage，跨合约月份和页面重载恢复，优先于参考值。清空或无效输入不写入偏好。存储受限时仅保留当前页面会话，并显示提示。读取分享参数保持链接中的数值，不主动联网或覆盖本机偏好。
- 取价刷新仍只刷新价格，不改写乘数、保证金和止损价；参数请求与报价使用同一取消机制，编辑代码、手动改价、重置或加载链接后过期响应不再回填。已删除开多/开空默认止损比例的说明文字，保留按钮行为。

- 股票及场内基金：腾讯财经公开网页行情，HTTPS fetch + GBK 文本解析；支持沪深北 A 股、沪市 5 开头的场内基金、深市 15/16/18 开头的场内基金。513500、159915 已实测。
- 代码与简拼检索：腾讯 `smartbox.gtimg.cn/s3/`。输入 1–5 位数字时实时查询，并再次严格筛选股票代码包含所输入数字的结果；输入完整 6 位代码时精确匹配。简拼支持不区分大小写的至少两个字母/数字组合，例如 PAYH、GZMT、BP500。结果仅保留代码与沪深北市场一致的 A 股、ETF、LOF，排除指数、境外证券和场外基金；去重后最多显示十项。北交所完整代码不依赖检索目录覆盖。
- 国内期货：东方财富 `futsse-static.eastmoney.com/redis` 提供品种与具体月份合约目录，`futsseapi.eastmoney.com/static/{市场}_{合约}_qt` 提供行情。输入部分或完整合约代码后实时列出具体月份合约，过滤主连、次主连及连续合约；选择后自动填入开仓价，并在同一个输入框外观内显示合约代码与名称。行情使用网页公开的应用标识和 JSONP 回调，响应中的 `p` 已经是实际价格，不再除以十进制倍数。验证 `dm`、`sc`、`p`、`zsjd`、`utime`。
- 期货输入框下方提供“开多”和“开空”：开多将止损价设为开仓价 × 80%，开空设为开仓价 × 120%。选定方向后，选择新合约或修改开仓价会继续按比例更新止损；手动修改止损价后取消方向按钮的自动跟随，再次点击方向按钮可恢复。分享参数保留方向及自动跟随状态。
- 页面初始、重置后及合约检索尚未成功时，开仓价和止损价均为空且不显示参数错误。开始输入新的合约代码会清空上一合约的两项价格；候选合约行情成功后只填开仓价，止损价由开多/开空按钮生成。查询失败时价格保持为空，也可手动输入。
- 股票卡片的买入价、止损价在空白状态下不显示文字占位提示，选中股票后再自动写入买入价及默认止损价。
- 股票买入价输入框的“元”字左侧提供循环刷新按钮：选中股票前不可用，选中后可随时重新获取该代码的现价。手动刷新只更新买入价，保留原止损价不变，并停止止损价对买入价的自动跟随；重新选择股票后恢复默认止损计算。
- 股票止损价输入框的“元”字左侧提供圆圈 × 按钮；止损价为空时不可用，点击后把止损价设为 `0` 并重新计算，表示按股价全部亏损测算。
- 股票代码不可重复添加：其他卡片已经选中的代码会从候选结果中排除；直接输入完整重复代码时提示“该股票已经添加”，并阻止取价。
- 期货开仓价格也提供相同的循环刷新按钮：选中具体合约后启用；手动刷新只更新开仓价，保留止损价，并取消开多/开空的自动止损跟随。
- 期货止损价格右侧提供圆圈 × 按钮；与股票“归零”不同，期货按钮会清空止损价，并取消开多/开空的自动止损状态。
- 手动修改止损或刷新开仓价格时保留已选择的开多/开空方向，仅停止比例跟随。开多止损须低于开仓价，开空止损须高于开仓价；方向不符或价格相等时，止损框及焦点边框显示红色并暂停仓位计算，修正后自动恢复。
- 简拼脚本和期货 JSONP 仅在 `sandbox="allow-scripts"` 的隐藏 iframe 中执行，不授予同源权限；各自 CSP 仅允许对应接口及初始化脚本，禁止其他资源、连接、表单。父页面校验消息来源窗口及随机请求标识，再验证数据。取消、超时及响应后均移除 iframe 和消息监听。
- Android 的 JavaScript bridge 可能注入子框架，因此 HTML 在检测到 AndroidApp 时阻止创建行情 iframe。以后更新联网 APK 时，应改用原生 HTTP 请求并仅向网页返回解析后的数据，不能直接开放 bridge 给远端脚本。
- 不在页面加载、切换市场、打开参数链接时查询。股票输入部分代码、完整代码或简拼后，暂停输入 300 毫秒实时显示候选项；无效及超过 6 位的数字输入不发请求。选择候选项后自动加载行情到买入价并计算仓位，失败时保留原价格并显示错误。期货采用相同交互：输入品种或部分合约代码（如 rb、rb27、IF26、SR7）显示具体月份候选，选择后自动填入开仓价；选择合约时同步填入乘数及资料基准保证金率，保证金率优先使用本品种的手动设置。
- 股票输入框按创建顺序提示“股票1代码/简拼”“股票2代码/简拼”直到“股票n代码/简拼”；新增卡片继续递增，重置后从 1 开始。代码与选中的名称合并显示，旁边的“删除”使用浅红色底纹突出显示，点击后立即删除，不提供撤销。候选项支持点击、触屏点选、方向键和回车选择，Esc 或点击外部关闭；编辑代码、删除、重置和载入参数时取消旧候选请求。没有展开候选项时，完整代码回车仍可直接取价；选中后再次打开候选项并选择，可更新报价。
- 选中或取价成功后以蓝色突出名称；长名称省略显示，完整名称可在候选项及“行情详情”中查看。改动代码时清除旧名称，防止把上一次查询的名称对应到新代码。
- 股票行情来源、时间和较早行情提示位于默认折叠的“行情详情”中，查询错误自动展开。
- 默认保留三张空白股票卡片，买入价和止损价均为空；完全空白的卡片不参与等风险分配与 CSV 导出，已开始填写但数据不完整的卡片仍需修正。
- 股票止损价默认跟随买入价 × 80%，消除浮点尾数后最多保留八位小数。手动修改止损价后停止跟随；清空止损价或更换股票代码后，下次填写/获取买入价会恢复自动填写。已保存的旧止损价作为手动值保留。
- 查询超时 12 秒。同一代码报价缓存 8 秒；简拼候选目录缓存 5 分钟（不缓存报价）。编辑代码或价格、删除、重置和载入新参数时取消旧请求，避免旧响应覆盖新输入。错误不覆盖原价格。
- 行情时间显示北京时间，超过 15 分钟标记“较早行情，可能休市或延迟”，不将请求时间冒充行情时间。
- 期货支持具体合约；郑商所使用三位年月代码（例如 SR701），其他市场四位（例如 rb2701 / IF2611）。候选目录只允许用户选择具体月份，不自动把主连替换为某个交易合约。品种映射根据 2026-10-24 读取的公开目录整理；新上市品种需维护。
- 参数格式保持 version 5，新增可选 `rows[].code` / `rows[].autoStop` / `futuresCode` / `futuresName` / `futuresDirection` / `futuresAutoStop`；旧链接仍可读取。CSV 增加代码与数量单位，代码按文本导出保留前导零。

## 运行

```powershell
node .\tests\test-quotes.cjs
node .\tests\test-quotes.cjs --live
node .\tests\test-quotes.cjs --layout
```

使用本机已有 Playwright 与 Chromium，不安装新依赖。第一条使用受控响应测试计算回归、报价解析、异常与取消逻辑、参数链接及 CSV；第二条再查询真实报价，并在主 HTML 和手机预览 iframe 中验证。测试不会构建 APK。

`--layout` 在回归检查后实测股票 002983、513500、部分代码 5135、PAYH、GZMT、BP500，以及期货部分代码 rb27 的候选匹配与选择后自动取价，检查默认止损、分享恢复及 360/390/430/1280px 布局，并在手机预览 iframe 中验证股票和期货的触屏点选。截图增加 `期货-合约候选.png`、`期货-代码与名称.png`。最新截图已目视检查：股票与期货均没有取价按钮，多候选列表可滚动，选择后代码与名称共用一个框；行情说明默认折叠，无横向溢出。

自动化记录：`results/quote-results.txt`；本次实际取价与目视检查记录：`results/live-quotes-2026-10-24.txt`。截图：项目的 `手机布局预览/行情-股票.png`、`行情-ETF.png`、`行情-期货.png`。

2026-10-24（周六）实测股票 600000、000001、920002，ETF 513500、159915，期货 rb2701、m2701、SR701、sc2612、IF2611、lc2701 均成功。这是最近可用报价验证，并非盘中更新频率保证；免费网页接口可能变更或暂时不可用。

初次尝试的 push2 股票通用接口能返回期货数据，但随后重定向至 push2delay 且出现跨域失败，最终实现使用期货网页本身的专用接口。`probe-quotes.cjs` 保留取数诊断过程，非生产依赖。
